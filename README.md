# Noxtell rules

Rules files for **Noxtell**, a social deduction game played around one iPad, starting with the **Possession** mode.

**Status: preview.** The rules files arrive here soon. The app doesn't load anything from this repository yet.

## What will be here
- Possession's rules, as data files: its roles, what each one does, the deal by table size, how each side wins, and the night order.
- The words players read and hear in Possession.
- The schema the files follow, so an editor can check them as you type.
